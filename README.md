# 출장 증빙철

출장 영수증을 날짜·항목별로 정리해 **A4 규격 증빙 문서**로 만들어 주는 웹앱입니다.
휴대폰에서 쓰도록 만들었습니다.

## 하는 일

1. 출장 기간을 입력하면 날짜별로 교통비·식비·숙박비 칸이 생깁니다.
2. 각 칸에 카드사에서 받은 영수증(이미지 또는 PDF)을 넣습니다.
3. **Word 저장**을 누르면 날짜·항목별로 페이지가 나뉜 `.docx` 파일이 만들어집니다.

한 칸에 여러 장을 넣으면 A4 한 장에 모아 배치하고, 5장부터는 다음 장으로 넘깁니다.
PDF는 페이지마다 잘라 각각 한 건의 영수증으로 다룹니다.

출력물은 좌측 상단에 날짜와 항목, 그 아래에 영수증이 오는 형태입니다.
한글(HWP)에서도 그대로 열리며, 열어서 다른 이름으로 저장하면 hwpx가 됩니다.

## 영수증은 어디에 저장되나

**서버로 전송되지 않습니다.** 이미지 변환, 문서 생성, 저장이 전부 브라우저 안에서 일어나고,
영수증은 기기의 브라우저 저장소에만 남습니다. 이 저장소는 접속한 주소 단위로 분리되므로,
같은 앱이라도 다른 주소로 들어가면 이전에 넣은 영수증이 보이지 않습니다.

iOS는 2주가량 방문하지 않은 사이트의 저장소를 정리합니다.
작업이 며칠에 걸친다면 중간에 한 번씩 Word로 저장해 두세요.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (외부 프레임워크 없음) |
| `pdf.min.js`, `pdf.worker.min.js` | PDF 영수증을 이미지로 변환 ([pdf.js](https://mozilla.github.io/pdf.js/) 3.11.174) |
| `icon.png` | 홈 화면 아이콘 |

`.docx` 생성은 라이브러리 없이 ZIP과 WordprocessingML을 직접 조립합니다.

## 설치

빌드 과정이 없는 정적 파일이라 어떤 호스팅에서도 동작합니다.
저장소에 파일을 올리고 Settings → Pages에서 브랜치를 지정하면 끝입니다.

## 휴대폰에서 쓰기

접속한 뒤 홈 화면에 추가하면 앱 아이콘이 생깁니다.
아이폰은 공유 → 홈 화면에 추가, 안드로이드는 크롬 메뉴(⋮) → 홈 화면에 추가입니다.

## 브라우저

iOS 15 이상 사파리와 안드로이드 크롬 기준으로 만들었습니다. 데스크톱 브라우저에서도 동작합니다.
PDF 변환은 `pdf.min.js`를 같은 폴더에서 먼저 찾고, 없으면 CDN을 시도합니다.
